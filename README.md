## 🎯 Overview

**Udemy Clone** is a professional frontend replica of Udemy's homepage built with vanilla **HTML5 and CSS3**. This project showcases advanced web design skills including responsive layouts, modern CSS features (Flexbox), and professional UI implementation without any frameworks or libraries.

### What Makes This Project Special

✅ **Fully Responsive** - Works seamlessly on mobile, tablet, and desktop  
✅ **Modern CSS** - Flexbox layouts, responsive design, professional styling  
✅ **Professional Design** - Matches Udemy's modern interface  
✅ **Clean Code** - Semantic HTML and well-organized CSS  
✅ **No Frameworks** - Pure HTML and CSS only  
✅ **Fast Loading** - Optimized performance  
✅ **Icon Integration** - Font Awesome icons for modern look  
✅ **Custom Fonts** - Google Fonts integration

## ✨ Features

### 🔝 Navigation Bar
- Professional navbar with Udemy branding (purple color)
- Centered search bar with magnifying glass icon
- Right-side navigation items (Course, My Learning, Cart, Notifications, User)
- Responsive and clean layout
- Border-bottom for separation

### 📂 Categories Section
- Horizontal category list with 6 categories
- **Categories:** Development, Business, IT & Software, Personal Development, Design, Marketing
- Styled with Udemy purple background (#A435F0)
- Rounded pill-shaped buttons
- Easy category browsing

### 🎯 Hero Section
- Full-width promotional banner
- High-impact visual for sales/promotions
- Responsive image sizing (100% width, 400px height)

### 💡 Recommended Courses Section
- Title: "Recommended for you"
- 4 featured course cards displayed horizontally
- Responsive grid layout with flexbox

**Course Card Features:**
- Course thumbnail image (responsive)
- Course title
- Instructor name
- Star rating (⭐)
- Price with original price strikethrough
- Courses: Python Data Viz, Web Dev Bootcamp, UI/UX Figma, Java Core

### 🏷️ Topics Section
- "Topics recommended for you"
- Grid of 9 technology topics
- Flexible layout that wraps on smaller screens
- Border-styled buttons with responsive sizing

**Topics:** Website, CSS, MongoDB, AWS, JavaScript, Azure, Docker, GitHub, React JS

### ⭐ Most Popular Section
- Title: "Most Popular"
- 8 course cards in responsive grid (4 cards per row on desktop)
- Professional layout with flexbox
- **Courses:** Git & GitHub, Software Testing, Cyber Security, Power BI, AI/ML, SQL Database, Django & Python, Cyber Security Fundamentals

### 🔗 Footer Section
- Two-part professional footer design
- Dark theme background (#1c1d1f)
- Links organized in 3 columns (Business, Company, Legal)
- Company branding and copyright information

**Footer Sections:**
- Business Links: Udemy Business, Teach on Udemy, Get the App, About Us, Contact Us
- Company Links: Careers, Blog, Help and Support, Affiliate, Investors
- Legal Links: Terms, Privacy Policy, Accessibility, Cookie Settings, Sitemap
- Copyright: Udemy Inc. All rights reserved
